# Included compression, XML and PNG components

The public core preview includes the following external implementations. Their
original licence files are reproduced verbatim beside this notice. Matching
source archives accompany the public preview source assets.

- zlib 1.3.1: z.library and linked PNG/icon support; `ZLIB-LICENSE.txt`.
- bzip2 1.0.8: bz2.library; `BZIP2-LICENSE.txt`.
- Expat 2.8.2: expat.library; `EXPAT-LICENSE.txt`.
- libpng 1.6.58: PNG datatype and icon image support; `LIBPNG-LICENSE.txt`.
