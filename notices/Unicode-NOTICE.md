# Unicode character data

The AROS standard C library contains generated Unicode character tables.
Their Unicode 18 source inputs, UnicodeData.txt and SpecialCasing.txt, are
retained with the matching corresponding-source release materials.

Copyright and licence terms are preserved in Unicode-LICENSE.txt (Unicode
License V3), copied verbatim from https://www.unicode.org/license.txt.
The original cached input files and generation/build scripts accompany the
public release so these tables can be regenerated from the actual inputs.
